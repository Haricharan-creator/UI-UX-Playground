Wireframing

Learn how to explore structure, content, interaction and layout before spending effort on visual polish.

Learn

Structure before decoration

A wireframe is a communication and exploration tool. It helps you test information hierarchy, content placement, navigation and key interactions without prematurely locking visual styling.

Designer question: If the colors, imagery and final typography disappeared, would the screen still communicate its purpose and structure?

Why is low-fidelity wireframing useful?

Apply

Build the challenge in Figma or Framer

Task

Create a low-fidelity checkout, onboarding or settings flow with three connected screens.

Constraints

Focus on content hierarchy, navigation, actions and states. Avoid spending time on final colors, imagery or decorative effects.

Then create a higher-fidelity version and explain which structural decisions survived the transition.
