Accessible Navigation Patterns

Learn to choose and design navigation patterns that make location, hierarchy and movement understandable across devices and interaction methods.

Learn

Pattern choice should follow the task

Navigation patterns such as tabs, menus, breadcrumbs, pagination and search solve different problems. Accessibility depends on clear structure, meaningful names, predictable behaviour and preserving context.

Designer question: Can a person tell where they are, what alternatives exist, what is selected, and how to move to the next useful place?
See

Pattern essentials

TabsUse for related views at the same level; make selection and keyboard behaviour clear.
BreadcrumbsHelp users understand location within a hierarchy when that context matters.
MenusKeep labels meaningful and interaction predictable across input methods.
PaginationCommunicate current position and available navigation clearly.
SearchProvide understandable labels, useful feedback and recoverable empty/error states.
Back pathsPreserve context so people can return without losing their place or work.

Apply

Pattern audit in Figma or Framer

Task

Choose a multi-level product or content flow. Identify the navigation pattern used at each level and document the user's current location.

Deliver

Create the key states for selected, focus, expanded, empty and back-navigation cases where relevant. Explain why each pattern fits the task.

Validate the implemented behaviour with keyboard and touch where applicable. Pattern names alone do not guarantee accessible behaviour.
