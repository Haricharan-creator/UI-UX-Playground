Typography is a system

Good interface typography makes content easier to scan and understand. Consider hierarchy, readable sizes, line height, contrast, text length and consistent roles rather than choosing type styles one element at a time.

Designer question: Can a user quickly distinguish the page title, supporting information, labels and actions without reading every word?
