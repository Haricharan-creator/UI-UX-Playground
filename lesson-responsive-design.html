Responsive Design

Learn how interfaces adapt across screen sizes, input contexts and content constraints while preserving the user's goal and clear interaction.

Learn

Responsive does not mean simply shrinking

A responsive interface adapts layout, content, spacing, controls and sometimes interaction patterns to the available space. The priority is to preserve usability and task completion, not to make every pixel identical.

Designer question: What must remain visible and usable when space, content length or input method changes?
