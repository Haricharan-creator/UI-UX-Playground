55. Screen Reader UX Awareness

Understand how structure, labels and state information can affect the experience when content is consumed non-visually.

LEARN

Design the information model, not only the pixels

Screen readers can expose headings, landmarks, labels, controls and state information. Designers should therefore think about semantic relationships and meaningful names alongside visual composition.

Designer question: If visual grouping disappeared, would the purpose and relationship of this content still make sense?

SEE
  • Give interactive controls meaningful names.
  • Use headings that reflect content structure.
  • Expose important state changes in understandable ways.
  • Do not put essential meaning only in decorative imagery.
  • Keep visual and semantic order aligned with the task.
CHECK

Which control label is more useful?

APPLY — FIGMA / FRAMER

Pick a flow with icon buttons, cards and dynamic states. Annotate the intended accessible name, heading level, landmark/region and state for each important element. Then inspect whether the visual order matches the task order.
