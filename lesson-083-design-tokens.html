83. Design Tokens

Turn recurring visual decisions into named, reusable values for colour, type, spacing, radius, elevation and motion.

Learn

Good tokens express intent rather than accidental values. Prefer semantic names such as text-primary or space-md, then map them to platform values.

  • Primitive values
  • Semantic tokens
  • Component mappings
  • Theme modes
  • Change management

Check

Which naming approach communicates intent best?

Tool practice

Build a small token set in Figma variables or your chosen design-system tool. Map it to buttons, fields and cards; then change one primitive and observe controlled propagation.

Loop: V1 → Review → V2 → Validate → Reflect
