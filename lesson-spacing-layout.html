Spacing communicates relationships

Spacing is not empty decoration. Consistent gaps help users understand which elements belong together and which groups are separate. Alignment creates predictable visual paths, while grids help maintain structure across screens.

Designer question: Which elements belong together, and does the spacing make that relationship obvious without extra explanation?
