Accessible Typography & Readability

Learn how type size, spacing, line length, hierarchy and responsive behaviour affect reading comfort and comprehension across people, devices and contexts.

Learn

Readable is a functional requirement

Typography is not only visual styling. People need to distinguish text, understand hierarchy and scan content at different sizes and distances. Good UX creates a readable system that remains useful when content, viewport or user settings change.

Designer question: Can people comfortably read, scan and understand the content when text becomes longer, the viewport changes or their preferred text size increases?

Typography accessibility essentials

HierarchyUse meaningful type hierarchy so headings, labels and body content are easy to distinguish.
Size & spacingChoose comfortable text size, line height and paragraph spacing for the intended context.
Line lengthAvoid overly long lines that make tracking from one line to the next difficult.
WeightUse weight and emphasis carefully; do not rely on very light text for important content.
Responsive typeEnsure typography adapts without clipping, overlap or loss of hierarchy.
Content resilienceTest long labels, translated text and user-controlled text sizing before finalising the layout.

Audit typography in Figma or Framer

Task

Choose a content-heavy screen. Audit heading hierarchy, body size, line height, paragraph spacing, line length and responsive behaviour.

Deliver

Create an improved type scale and test it with long labels, realistic content and increased text size. Record any layout failures and fixes.

Review both desktop and mobile frames. Do not judge readability from a single ideal viewport.
