Shortcuts that build real tool fluency

Use shortcuts as part of a task, not as memorization. Desktop references are separated by Mac and Windows. Mobile sections should describe capabilities and limitations instead of inventing desktop-equivalent shortcuts.

iOS / Android

HACHARA will teach mobile capabilities separately from desktop shortcuts. Each lesson will identify whether the action is available, review-only, presentation-oriented, or unavailable on the mobile app. This prevents learners from being taught a desktop shortcut that cannot be used on mobile.

Learning rule: If a shortcut or feature changes by platform, HACHARA will show the platform explicitly instead of using a misleading generic shortcut.
Tool wisdom: Shortcuts are taught inside practical tasks — learn → try → apply → review — so learners develop workflow fluency rather than memorizing a cheat sheet.
