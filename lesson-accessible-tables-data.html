Accessible Data & Tables

Learn how to structure data so people can understand relationships, compare values and find important information using different screen sizes and assistive technologies.

Learn

Structure carries meaning

A visually neat table is not automatically accessible. People need to understand headers, relationships, units, ordering and changes in values. When data becomes complex, choose a representation that matches the task.

Designer question: Can someone identify what each value means, understand its relationship to its row or column, and complete the intended comparison without relying only on visual position or colour?

Data accessibility essentials

HeadersMake row and column relationships clear.
UnitsState units and meaningful context instead of making users infer them.
OrderUse logical reading and sorting order.
ContrastEnsure text and important visual distinctions remain perceivable.
AlternativesProvide an appropriate alternative when a dense visualisation is not usable for everyone.
Responsive dataChoose whether data should reflow, scroll, simplify or change representation without losing essential meaning.

Apply

Design an accessible data view in Figma or Framer

Task

Choose a dashboard, comparison table or report. Identify headers, units, sorting, status indicators and the most important user questions.

Deliver

Create desktop and narrow-screen states. Define how the data reflows or scrolls and how colour-dependent status information is supplemented.

For implementation, validate semantic table structure, reading order, keyboard access and real assistive-technology behaviour. A visual mockup cannot prove those properties.
