85. Component States

Design the meaningful states a component can enter so users understand status, availability, progress and recovery.

Learn

Common states include default, hover, focus, pressed, selected, disabled, loading, success and error. Only include states relevant to the component and task.

State quality

  • Distinct and understandable
  • Accessible focus and feedback
  • Consistent across contexts
  • Recoverable where appropriate

Check

Why define states before handoff?

Tool practice

Choose one interactive component. Create a state matrix in Figma/Framer, prototype transitions and test keyboard, touch and error paths.

Loop: V1 → Review → V2 → Validate → Reflect
