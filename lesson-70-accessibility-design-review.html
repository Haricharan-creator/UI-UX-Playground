70. Accessibility Design Review

Bring accessibility thinking together into a repeatable design review before handoff.

Learn

Review content, structure, keyboard access, focus, colour, typography, forms, media, motion, responsive behaviour and recovery. Prioritize barriers by user impact and task criticality.

Check

Can the review produce concrete issues, evidence, owners and rework actions rather than a vague accessibility score?

Figma / Framer Practice

Select one end-to-end flow. Run a structured review, annotate evidence, create fixes and compare V1 with V2.

Knowledge Check

What makes an accessibility review useful?

  1. A checklist with no evidence.
  2. Specific findings tied to user tasks, evidence, severity and actionable fixes.
  3. Only visual inspection.

Answer: 2.

Rework

V1 → Review → Evidence → V2 → Validate → Reflect.
