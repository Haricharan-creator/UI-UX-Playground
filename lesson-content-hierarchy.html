54. Content Hierarchy

Help people understand what matters first, what supports it and what action is available.

LEARN

Hierarchy is a decision aid

Hierarchy combines content order, typography, spacing, grouping and emphasis. A strong hierarchy lets users scan before reading deeply and makes the primary task apparent without making everything visually loud.

Designer question: If someone looks at this screen for three seconds, can they identify the purpose and next useful action?

SEE
  • Lead with the screen's primary purpose.
  • Group related information.
  • Use one clear primary emphasis where appropriate.
  • Reserve strong visual weight for meaningful differences.
  • Let spacing and alignment reinforce relationships.
CHECK

What is a useful hierarchy strategy?

APPLY — FIGMA / FRAMER

Choose a cluttered screen. Mark the primary goal, supporting content and secondary actions. Create V2 using grouping, spacing, type scale and emphasis. Compare screenshots and explain every hierarchy change.

Loop: V1 → Hierarchy map → V2 → Three-second scan → Reflect
