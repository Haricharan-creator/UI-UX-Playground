68. Voice & Conversational Accessibility

Design voice and conversational interactions that remain understandable, recoverable and optional.

Learn

Use clear prompts, confirmations for consequential actions, visible alternatives and graceful recovery. Never make voice the only path when another practical input is needed.

Check

Can a person understand system state and recover if speech recognition fails?

Figma / Framer Practice

Map a voice-assisted flow with listening, success, ambiguity, timeout and fallback states. Add visible controls.

Knowledge Check

What strengthens voice UX?

  1. One-shot commands with no recovery.
  2. Clear prompts, confirmations and fallback paths.
  3. Hide the visual state.

Answer: 2.
