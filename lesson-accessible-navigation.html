Accessible Navigation & Focus

Learn how to design predictable navigation and visible focus so people can move through an interface with keyboards, switch devices, screen readers and other interaction methods.

Learn

Navigation is a mental map

People need to know where they are, where they can go and what will happen when they activate an item. Consistent structure, meaningful labels and logical focus order reduce cognitive and interaction barriers.

Designer question: If someone cannot use a pointer, can they still understand where they are, move through the interface and reach the same important actions?

Navigation essentials

HierarchyUse clear information architecture and meaningful headings.
LabelsName links and controls by purpose rather than appearance.
Focus orderKeep keyboard movement logical and consistent with the visual flow.
Visible focusMake the currently focused control easy to identify.
Skip pathsProvide efficient ways past repeated content where appropriate.
StateCommunicate current, expanded, selected or disabled states clearly.

Apply

Audit navigation in Figma or Framer

Task

Choose a multi-screen flow. Map headings, navigation items, focus order, current states, modal entry/exit and repeated navigation.

Deliver

Annotate the prototype with intended keyboard/focus behaviour and identify barriers. Then test the implemented interface with keyboard navigation where available.

Remember that a visual prototype can communicate intended behaviour, but real accessibility must be validated in the implemented product.
