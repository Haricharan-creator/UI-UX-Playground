60. Inclusive UX Audit

Bring the accessibility and inclusion principles together into a repeatable design-review practice.

LEARN

Audit the whole task, not isolated pixels

An inclusive UX audit considers structure, content, colour, typography, input, focus, feedback, motion, media, errors and recovery across the actual user journey. Findings should include evidence, impact, location and a practical recommendation.

Designer question: Where can a user encounter a barrier from entry to completion, and what evidence supports that finding?

SEE
  • Check perception: contrast, type, media and non-colour cues.
  • Check operation: keyboard, touch, target size and alternatives.
  • Check understanding: language, hierarchy, status and instructions.
  • Check recovery: errors, undo, persistence and exit paths.
  • Prioritise findings by impact and task criticality, then validate fixes.
