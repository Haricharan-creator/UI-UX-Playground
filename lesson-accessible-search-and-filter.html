Accessible Search & Filters

Learn how to make search, sorting and filtering understandable, operable and recoverable across different input methods and assistive technologies.

Learn

Finding content should not become a puzzle

Search and filtering can reduce effort, but unclear labels, hidden filter states, confusing result updates or lost selections can create barriers. Make the controls, current criteria and results understandable.

Designer question: Can the person tell what they searched or filtered, what changed, how many results remain, and how to clear or revise the criteria?
See

Search and filter essentials

Clear labelsUse meaningful names for search, filter and sort controls.
Current criteriaMake active filters and sort order visible and understandable.
Result feedbackCommunicate useful result changes without relying only on visual movement.
Clear allOffer an understandable way to remove criteria and recover from over-filtering.
PersistencePreserve useful selections when moving through results where appropriate.
Empty statesExplain why no results appear and provide useful next steps.

Task

Choose a catalogue, dashboard or content-search flow. Map search, filter, sort, result update, empty and clear states.

Deliver

Prototype active criteria, result feedback, clear/reset behaviour and empty-result recovery. Document keyboard/focus expectations for implemented controls.

When implemented, validate result updates and focus behaviour with realistic data and interaction methods.
