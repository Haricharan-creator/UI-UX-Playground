# Bundle Engine — Content Preservation Gate v1.0

## Authoritative curriculum
- 117 lessons are the current extended curriculum.
- 90 lessons are the original curriculum milestone.
- 117/117 is the completed learning milestone.
- Lesson identity and numbering are preserved.

## Mapping rule
Bundle → Module → Lesson is an organizational layer only.

It must never:
- rewrite lesson source text
- renumber lessons
- merge lessons without provenance
- invent missing lesson content
- convert source gaps into completed content
- treat lesson completion as application certification

## Source-gap rule
Known historical source gaps remain explicit until authoritative material is recovered. Current recovered records and current-chat supplemental captures must not silently overwrite the master registry.

## Build sequence
1. Recover authoritative source.
2. Reconcile lesson registry.
3. Preserve exact source content.
4. Map lessons into bundles/modules.
5. Attach skills and evidence requirements.
6. Build practice and Figma/Framer tasks.
7. Test learner workflow.
8. Regression test.

## Certification boundary
The learning milestone is complete, but application/device/release certification remains separate. A build must not be marked final merely because 117/117 lessons exist.
