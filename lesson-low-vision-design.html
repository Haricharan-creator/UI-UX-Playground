56. Designing for Low Vision

Build interfaces that remain understandable when users need magnification, stronger contrast, larger text or reduced visual density.

LEARN

Zoom should not break the task

Low-vision users may enlarge content or use assistive settings. Robust layouts should tolerate increased text size and magnification without clipping, overlap or hidden controls.

Designer question: What happens to this layout when text becomes substantially larger or the user views only a magnified portion?

SEE
  • Use strong text and UI contrast.
  • Allow text to grow without overlap.
  • Avoid conveying information through tiny visual differences.
  • Keep controls large enough to identify and operate.
  • Maintain meaningful relationships when content reflows.
CHECK

APPLY — FIGMA / FRAMER

Choose a dense screen. Create a stress version with longer content and significantly larger text. Identify clipping, overlap, hidden actions and lost hierarchy; redesign the affected components.
