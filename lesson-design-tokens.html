Design Tokens

Learn how reusable values for color, typography, spacing, radius and other visual decisions create a scalable foundation for a design system.

Learn

Make repeated decisions reusable

A design token represents a named design value so it can be reused consistently across components and products. Tokens help teams change a system systematically rather than hunting through individual screens.

Designer question: Which values repeat often enough that naming and reusing them would improve consistency, maintenance or accessibility?

Why are design tokens useful?

Apply

Build a token starter set

Task

Choose a Figma or Framer project and identify repeated colors, spacing values, text styles and corner radii.

Build

Create named tokens/variables or styles, replace repeated one-off values, and document where each should be used.

Check contrast and readability after tokenising. A token system should support good UX, not merely standardise visual values.
