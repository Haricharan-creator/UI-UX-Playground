75. Feedback & System Status

Make system responses visible, timely and understandable so users can build an accurate mental model.

Learn

Use immediate feedback for actions, progress for longer operations and clear completion or failure states. Match feedback strength to consequence and urgency.

Check

Does the interface acknowledge important actions and communicate meaningful state changes?

Figma / Framer Practice

Choose a save, upload or submission flow. Prototype idle, processing, progress, success and failure feedback.

Knowledge Check

What should feedback do?

  1. Leave system state ambiguous.
  2. Confirm meaningful changes and guide the next action.
  3. Use animation without information.

Answer: 2.
